A principal novidade da 0.10.0 é o Spraxium RPC. Agora você pode chamar um método do bot pelo backend e usar a resposta em um painel, script ou outro serviço. Isso facilita a integração de quem mantém um bot junto de uma aplicação web, aproveitando o que ele já faz e mantendo a conexão com o Discord no próprio bot.

O bot recebe as chamadas com `@spraxium/rpc`, e o backend usa `@spraxium/rpc-client` para enviá-las. As chamadas têm tipos, autenticação e um tempo limite. Se o bot usa sharding nativo, o Spraxium encaminha a operação para o shard responsável pelo servidor. Os tutoriais mostram desde a primeira chamada até a integração com backends como NestJS e Express. [Comece pelo RPC](/pt/guide/rpc-quickstart).

## Por que estamos deixando o HTTP

Com o `@spraxium/http`, a gente mantinha um servidor web dentro do bot, incluindo rotas, middleware, CORS, validação e tratamento de erros HTTP. Muitos projetos já tinham um backend fazendo esse trabalho. Na prática, isso significava manter recursos parecidos em dois lugares e gastar tempo com problemas que os frameworks web já resolvem.

O RPC permite concentrar esse esforço na comunicação entre o backend e o bot. Seu framework web cuida da API pública, do login e das permissões de cada usuário, enquanto o Spraxium recebe as chamadas aos métodos do bot e as encaminha entre os shards. Você também pode seguir usando o framework que já conhece no backend.

Por isso, o `@spraxium/http` está descontinuado. Quem já usa o pacote pode migrar uma rota por vez e manter as URLs que o painel chama hoje. Preparamos um guia que acompanha essa troca, mostrando o que muda no bot e no backend. [Veja como migrar](/pt/guide/rpc-http-migration).

## Documentação que acompanha a versão do bot

A documentação passa a ter textos separados para cada versão suportada do framework. Assim, você pode consultar as instruções da versão instalada no seu bot e mudar de guia quando for atualizar. As docs mais recentes abrem por padrão, e a versão 0.9.0 continua disponível na sidebar.

Também revisamos os guias, atualizamos exemplos e retiramos instruções que já não correspondiam ao funcionamento do framework. Algumas partes precisavam de mais contexto, então os tutoriais de RPC agora acompanham a chamada do backend até o bot, e os guias de ambiente mostram como organizar os validadores conforme o projeto cresce. Dá para acompanhar a implementação pelo guia mesmo quando você está conhecendo o recurso.

## Skills para agentes de código

O site ganhou um catálogo de skills para trabalhar com Spraxium usando agentes de código. Cada skill reúne instruções para uma tarefa, com exemplos e referências para a documentação. Há guias para iniciar um projeto, criar comandos e componentes, usar guards, configurar tarefas agendadas, trabalhar com logs e outras partes do framework.

Você pode ler o guia no site e baixar o arquivo para usar com seu agente. A skill geral ajuda a encontrar o assunto certo, conferir a versão instalada e seguir a estrutura dos exemplos oficiais. Também há uma skill dedicada à migração do HTTP para o RPC, com os passos e o contexto dessa mudança. [Conheça as skills](/pt/skills).

## Mudanças no site

Refizemos o design de várias partes do site e melhoramos a navegação entre guias, pacotes, artigos e notas de versão. O layout ficou mais consistente, os menus estão mais fáceis de usar e as docs mantêm sua posição na sidebar ao abrir outra página. Com isso, a experiência fica mais fluida e organizada, e você consegue continuar a leitura com menos interrupções.
