O suporte ao Node.js 20 termina no Spraxium 0.3.0. Essa versão passa a exigir Node.js 22.23.2 ou superior, abaixo do Node.js 27, incluindo as versões suportadas das linhas 24 e 26. A mudança permite manter o framework e suas ferramentas em versões do runtime que ainda recebem manutenção.

## Atualize o ambiente em que o bot roda

Antes de instalar os pacotes atualizados, confira o Node.js no seu computador, no servidor e nos containers ou jobs de CI que fazem o build do bot. Atualizar só a instalação local pode deixar o bot publicado em um runtime antigo.

```sh
node --version
```

Para essa versão, o resultado precisa ser pelo menos `v22.23.2` e ficar abaixo de `v27.0.0`. Depois de atualizar o runtime, instale os pacotes e inicie o bot pelo processo que já usa.

Esses requisitos correspondem à versão 0.3.0. Ao instalar uma versão posterior do Spraxium, consulte a documentação dela para conferir os requisitos de Node.js.
