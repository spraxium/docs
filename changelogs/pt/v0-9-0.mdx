Durante o desenvolvimento, publicamos uma build como `1.0.0` antes de concluir o trabalho previsto para esse lançamento. O número dava a entender que a versão 1.0 já estava pronta. Com a 0.9.0, reunimos os pacotes em uma linha de versões comum para ficar mais fácil identificar quais foram lançados juntos.

## A mesma versão para os pacotes

Todos os pacotes Spraxium foram publicados como `0.9.0`. Se seu bot usa vários deles, você pode manter o mesmo número ao atualizar. Isso também ajuda na hora de explicar como está a instalação quando aparece um problema.

O desenvolvimento da 1.0 passou para uma branch própria. Assim, pudemos continuar esse trabalho enquanto mantínhamos as versões estáveis que já estavam em uso.

## Atualizações de dependências

Essa versão também atualizou dependências com vulnerabilidades conhecidas, incluindo o `minimatch` usado pela CLI, o `@hono/node-server` do pacote HTTP e o `glob` do workspace. As correções entraram nos pacotes publicados como 0.9.0. [Veja as mudanças do lançamento](https://github.com/spraxium/spraxium/commit/259818c36f434448167a3d65a2ee9b58e7cc09e4).
