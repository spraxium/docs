Spraxium 0.9.1 incorpora `spraxium use` para cambiar la versión del framework en un bot existente. Con esta entrega abrimos el canal `next` con `1.0.0-dev.1`, la primera versión preliminar del trabajo en la 1.0. Puedes probar los cambios en un proyecto y volver después a la versión estable.

## Cambia de versión desde tu proyecto

Ejecuta el comando en la carpeta del bot. El dry run muestra qué paquetes cambiarían, para que revises el resultado antes de instalar.

```sh
spraxium use next --dry-run
spraxium use next
spraxium use stable
```

La CLI comprueba que npm tenga la versión elegida para cada paquete Spraxium declarado por el bot. Después fija todos en la misma versión y actualiza el lockfile con el gestor de paquetes del proyecto. Si la instalación falla o resuelve una versión distinta, recupera los archivos anteriores e intenta reinstalar esas dependencias.

También puedes indicar una versión exacta, como `spraxium use 1.0.0-dev.1`, cuando necesitas reproducir un error. Volver a ejecutar `use next` instala la versión preliminar disponible en ese momento, mientras que `use stable` sigue la etiqueta `latest` de npm. [Guía para cambiar de versión](/es/guide/cli-use).

## Identifica la build que está en marcha

La salida de inicio ahora identifica las builds de desarrollo, incluso cuando el bot arranca sin conexión a internet. Los avisos de actualización siguen el canal instalado. Un bot estable recibe actualizaciones estables y una versión preliminar puede avisar de una build más reciente de la misma serie. Cuando hay una versión estable más nueva, ese aviso tiene prioridad. La consulta se hace en segundo plano y guarda el resultado durante 24 horas.

La primera versión preliminar incluye una entrada CommonJS para Signal Client, almacenamiento compartido de nonces en Redis para bots con varias instancias y ajustes en el descubrimiento y la ejecución de tareas programadas con Redis. Si usas esas funciones, prueba el inicio y los reinicios habituales de tu bot e incluye la versión instalada al comunicar un problema.
