Spraxium 0.3.0 deja de admitir Node.js 20. Esta versión requiere Node.js 22.23.2 o superior, por debajo de Node.js 27, incluidas las versiones compatibles de las ramas 24 y 26. El cambio nos permite mantener el framework y sus herramientas en versiones del entorno que siguen recibiendo mantenimiento.

## Actualiza el entorno donde corre el bot

Antes de instalar los paquetes actualizados, comprueba Node.js en tu ordenador, en el servidor y en los contenedores o trabajos de CI que compilan el bot. Actualizar solo la instalación local puede dejar el bot desplegado en una versión antigua.

```sh
node --version
```

Para esta versión, el resultado debe ser al menos `v22.23.2` y estar por debajo de `v27.0.0`. Después de actualizar el entorno, instala los paquetes e inicia el bot con tu proceso habitual.

Estos requisitos corresponden a la versión 0.3.0. Si instalas una versión posterior de Spraxium, consulta su documentación para comprobar qué versiones de Node.js admite.
