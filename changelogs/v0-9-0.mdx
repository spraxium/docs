During development, we published a build as `1.0.0` before the work planned for that release was ready. That number made it look as though Spraxium 1.0 had shipped. With 0.9.0, we brought the packages back to a shared release line so it's easier to know which versions belong together.

## A shared version for the framework

All Spraxium packages were released together at `0.9.0`. If your bot uses several of them, you can keep them on the same number when updating. This also makes it easier to describe your installation when reporting a problem.

We moved 1.0 development to its own branch. That gave us room to continue that work while maintaining the stable releases people were already using.

## Dependency updates

This release also updated dependencies that had known vulnerabilities, including `minimatch` in the CLI, `@hono/node-server` in the HTTP package, and `glob` in the workspace. These fixes were included in the packages released under 0.9.0. [View the release changes](https://github.com/spraxium/spraxium/commit/259818c36f434448167a3d65a2ee9b58e7cc09e4).
