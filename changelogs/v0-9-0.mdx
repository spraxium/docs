During development, we accidentally published a build to npm as `1.0.0` before the work planned for that release was ready. The version on npm made it look like 1.0 had already shipped.

## One version across the framework

We published all Spraxium packages together at `0.9.0`. If your bot uses several `@spraxium/*` packages, the shared version makes it easier to tell which ones were released together.

We moved 1.0 development to its own branch so we could keep maintaining the stable release line while work on the next major version continued.

## Dependency security updates

As part of our regular maintenance, we updated several dependencies to versions that address known vulnerabilities. That included `minimatch` in the CLI, `@hono/node-server` in `@spraxium/http`, and `glob` in the workspace. [Release changes](https://github.com/spraxium/spraxium/commit/259818c36f434448167a3d65a2ee9b58e7cc09e4)
