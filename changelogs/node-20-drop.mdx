With Spraxium 0.3.0, support for Node.js 20 ends. This release requires Node.js 22.23.2 or newer, below Node.js 27, including the supported Node.js 24 and 26 releases. The change lets us keep the framework and its tools on maintained runtimes.

## Update the environment where the bot runs

Before installing the updated packages, check Node.js on your computer, on the server, and in any container or CI job that builds the bot. Updating the local installation alone can leave the deployed bot on an older runtime.

```sh
node --version
```

For this release, the result needs to be at least `v22.23.2` and below `v27.0.0`. Once the runtime is updated, install the packages and start the bot through your usual process.

These requirements describe the 0.3.0 release. When installing a later Spraxium version, check its documentation for the matching Node.js requirements.
