## Node.js 20 support has ended

Spraxium no longer supports Node.js 20. The minimum required version is now Node.js 22.23.2, with support for newer releases below Node.js 27, including Node.js 24 and 26. This change keeps the framework aligned with maintained Node.js releases and allows its packages and development tools to use newer runtime improvements safely.

## Upgrading

Update Node.js before installing the latest Spraxium packages. No application code changes are required as part of this migration.

```bash
node --version
```

The output must be `v22.23.2` or newer and remain below `v27.0.0`.
