## El bloque dev

El bloque _dev_ controla el watcher de desarrollo local que reinicia el proceso de tu bot cuando cambian los archivos fuente. Todos los campos son opcionales. El entrypoint predeterminado es `src/main.ts` y el debounce predeterminado es de 300 milisegundos; la mayoría de proyectos solo necesitan ajustar _debounce_ para evitar tormentas de reinicios durante guardados rápidos.

```typescript filename="spraxium.config.ts"
import { defineConfig } from '@spraxium/core';

export default defineConfig({
  dev: {
    entrypoint: 'src/main.ts',
    debounce: 500,
    include: ['locales'],
    exclude: ['.spraxium/**', 'dist/**'],
  },
});
```

<Callout tone="warning" title="Excluye directorios generados">
  Agrega siempre .spraxium/** y dist/** a la lista *exclude*. Estos
  directorios cambian durante operaciones de build, y observarlos causa bucles
  infinitos de reinicio que desestabilizan el proceso del watcher.
</Callout>

## Resolución del entorno

`NODE_ENV` se lee una sola vez durante el inicio y se mapea a un objeto _ConfigEnv_. Este valor nunca cambia después de cargar la configuración, por lo que toda bifurcación basada en entorno debe ocurrir dentro de tu callback de _defineConfig_.
