## Cómo funciona el array plugins

Cada entrada en el array _plugins_ es un objeto plano con dos propiedades: un string _namespace_ que identifica de forma única al plugin y una carga _config_ con sus opciones. Nunca creas este objeto manualmente. Los paquetes de plugins exportan helpers de factory tipados como _defineHttp_, _defineI18n_, _defineSchedule_ y _defineSignal_ que producen entradas con la forma correcta y con inferencia completa en TypeScript. El framework resuelve la configuración de cada plugin en runtime emparejando el namespace, por lo que cambiar un plugin nunca afecta a otro.

```typescript filename="spraxium.config.ts"
import { defineConfig } from '@spraxium/core';
import { defineHttp } from '@spraxium/http';
import { defineI18n } from '@spraxium/i18n';
import { defineSchedule } from '@spraxium/schedule';

export default defineConfig({
  plugins: [
    defineI18n({
      defaultLocale: 'en-US',
      references: [{ name: 'commands', path: './locales' }],
    }),
    defineHttp({
      enabled: true,
      port: 3001,
      host: 'localhost',
      apiKey: process.env.HTTP_API_KEY ?? 'dev-secret',
      sharding: false,
    }),
    defineSchedule({
      timezone: 'America/Sao_Paulo',
      defaultLockTtlMs: 60_000,
      disableAll: false,
    }),
  ],
});
```

## Extraer la configuración de plugins en archivos separados

En proyectos con varios plugins, mantener todas las llamadas de factory inline en `spraxium.config.ts` vuelve el archivo difícil de revisar. El patrón recomendado es extraer la llamada de factory de cada plugin a un archivo dedicado dentro de `config/`, exportar el resultado como constante con nombre e importarlo en la configuración raíz. Esto mantiene las opciones de cada plugin aisladas y auditables de forma independiente.

<CodeTabs>
  <Tab label="config/schedule.config.ts" language="typescript">
```typescript filename="config/schedule.config.ts"
import { defineSchedule } from '@spraxium/schedule';

export const schedulePlugin = defineSchedule({
  timezone: 'America/Sao_Paulo',
  defaultLockTtlMs: 60_000,
  disableAll: false,
});
```
  </Tab>
  <Tab label="config/http.config.ts" language="typescript">
```typescript filename="config/http.config.ts"
import { defineHttp } from '@spraxium/http';

export const httpPlugin = defineHttp({
  enabled: true,
  port: 3001,
  host: 'localhost',
  apiKey: process.env.HTTP_API_KEY ?? 'dev-secret',
  sharding: false,
});
```
  </Tab>
  <Tab label="spraxium.config.ts" language="typescript">
```typescript filename="spraxium.config.ts"
import { defineConfig } from '@spraxium/core';
import { httpPlugin } from './config/http.config';
import { schedulePlugin } from './config/schedule.config';

export default defineConfig({
  plugins: [httpPlugin, schedulePlugin],
});
```
  </Tab>
</CodeTabs>

<Callout tone="success" title="Mantén la configuración cerca del import de la factory">
  Cuando el namespace y la carga están visibles juntos en el mismo archivo, las
  auditorías y refactors son significativamente más rápidos. Evita repartir
  opciones de plugins entre módulos utilitarios o archivos de constantes
  compartidos para otros fines.
</Callout>
