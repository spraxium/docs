## O bloco dev

O bloco _dev_ controla o watcher de desenvolvimento local que reinicia o processo do bot quando os arquivos-fonte mudam. Todos os campos são opcionais. O entrypoint padrão é `src/main.ts`, e o debounce padrão é de 300 milissegundos; a maioria dos projetos só precisa ajustar _debounce_ para evitar tempestades de reinicialização durante salvamentos rápidos.

```typescript filename="spraxium.config.ts"
import { defineConfig } from '@spraxium/core';

export default defineConfig({
  dev: {
    entrypoint: 'src/main.ts',
    debounce: 500,
    include: ['locales'],
    exclude: ['.spraxium/**', 'dist/**'],
  },
});
```

<Callout tone="warning" title="Exclua diretórios gerados">
  Sempre adicione .spraxium/** e dist/** à lista *exclude*. Esses diretórios
  mudam durante operações de build, e observá-los causa loops infinitos de
  reinicialização que desestabilizam o processo do watcher.
</Callout>

## Resolução de ambiente

`NODE_ENV` é lido uma vez na inicialização e mapeado para um objeto _ConfigEnv_. Esse valor nunca muda depois que a config é carregada, então toda ramificação baseada em ambiente precisa acontecer dentro do callback de _defineConfig_.
