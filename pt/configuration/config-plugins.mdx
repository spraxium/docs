## Como o array plugins funciona

Cada entrada no array _plugins_ é um objeto simples com duas propriedades: uma string _namespace_, que identifica o plugin de forma única, e uma carga _config_ com suas opções. Você nunca cria esse objeto manualmente. Pacotes de plugin exportam helpers de factory tipados, como _defineHttp_, _defineI18n_, _defineSchedule_ e _defineSignal_, que produzem entradas no formato correto com inferência completa de TypeScript. O framework resolve a configuração de cada plugin em runtime fazendo match pelo namespace, então mudar um plugin nunca afeta outro.

```typescript filename="spraxium.config.ts"
import { defineConfig } from '@spraxium/core';
import { defineHttp } from '@spraxium/http';
import { defineI18n } from '@spraxium/i18n';
import { defineSchedule } from '@spraxium/schedule';

export default defineConfig({
  plugins: [
    defineI18n({
      defaultLocale: 'en-US',
      references: [{ name: 'commands', path: './locales' }],
    }),
    defineHttp({
      enabled: true,
      port: 3001,
      host: 'localhost',
      apiKey: process.env.HTTP_API_KEY ?? 'dev-secret',
      sharding: false,
    }),
    defineSchedule({
      timezone: 'America/Sao_Paulo',
      defaultLockTtlMs: 60_000,
      disableAll: false,
    }),
  ],
});
```

## Extraindo a config do plugin para arquivos separados

Em projetos com vários plugins, manter todas as factory calls inline em `spraxium.config.ts` deixa o arquivo difícil de revisar. O padrão recomendado é extrair a factory call de cada plugin para um arquivo dedicado dentro de `config/`, exportar o resultado como uma constante nomeada e importá-la na config raiz. Isso mantém as opções de cada plugin isoladas e auditáveis de forma independente.

<CodeTabs>
  <Tab label="config/schedule.config.ts" language="typescript">
```typescript filename="config/schedule.config.ts"
import { defineSchedule } from '@spraxium/schedule';

export const schedulePlugin = defineSchedule({
  timezone: 'America/Sao_Paulo',
  defaultLockTtlMs: 60_000,
  disableAll: false,
});
```
  </Tab>
  <Tab label="config/http.config.ts" language="typescript">
```typescript filename="config/http.config.ts"
import { defineHttp } from '@spraxium/http';

export const httpPlugin = defineHttp({
  enabled: true,
  port: 3001,
  host: 'localhost',
  apiKey: process.env.HTTP_API_KEY ?? 'dev-secret',
  sharding: false,
});
```
  </Tab>
  <Tab label="spraxium.config.ts" language="typescript">
```typescript filename="spraxium.config.ts"
import { defineConfig } from '@spraxium/core';
import { httpPlugin } from './config/http.config';
import { schedulePlugin } from './config/schedule.config';

export default defineConfig({
  plugins: [httpPlugin, schedulePlugin],
});
```
  </Tab>
</CodeTabs>

<Callout tone="success" title="Mantenha a config perto do import da factory">
  Quando o namespace e a carga estão visíveis juntos no mesmo arquivo,
  auditorias e refactors ficam significativamente mais rápidos. Evite espalhar
  opções de plugin por módulos utilitários ou arquivos de constantes
  compartilhados usados para outras finalidades.
</Callout>
